# Quiz Maker

Take a photo of your class notes, and Quiz Maker turns them into a multiple-choice quiz. Tap an answer to find out straight away if you got it right, with an explanation, and see your score at the end.

## The problem
Many students study by only re-reading their notes. Testing yourself is one of the best ways to learn, but writing good practice questions takes time, and many students don't have tutors or past papers.

## The solution
Upload a photo of your notes. The app reads them with **Gemma 4**, Google's open model that understands text and images. It then:
- Writes 5 multiple-choice questions with 4 options each
- Lets you tap an answer and tells you if it is correct or not
- Explains the right answer
- Shows your final score
- Works in English, French, Wolof, or Mandinka

## Who it helps
- Students preparing for exams
- Learners without access to tutors or practice books
- Teachers who want quick practice questions from lesson notes

## How it works
1. Upload a photo of your notes and choose a language
2. The app sends the image and a prompt to Gemma 4
3. Gemma returns the questions, options, answers, and explanations
4. The app shows one question at a time and checks your answer

## Built with
- Python
- Gradio (the web interface)
- Gemma 4 (open-weight model), through Google AI Studio or locally with Ollama

## Files in this repo
- `quiz_interactive.py`: interactive quiz using Gemma 4 through Google AI Studio
- `quiz_local.py`: the same interactive quiz running fully offline with Ollama
- `quiz.py`: simple version that shows all questions with an answer key at the end
- `app.py`: **Simple Explain**, a second tool that explains photos of confusing documents in plain language

## How to run it (with Google AI Studio)
1. Install Python and run: `pip install google-genai gradio pillow`
2. Get a free API key from aistudio.google.com
3. Set it as an environment variable named `GEMINI_API_KEY`
4. Run: `python quiz_interactive.py`
5. Open the link shown in the terminal (usually http://127.0.0.1:7860)

## Run fully offline with Ollama
1. Install Ollama from ollama.com
2. Run: `ollama pull gemma4:e2b`
3. Run: `pip install ollama gradio`
4. Run: `python quiz_local.py`
5. Open http://127.0.0.1:7860

No API key and no internet connection are needed for this version.

## Limitations
- Wolof and Mandinka output may be less accurate than English and French. Improving this is a next step.
- Questions are generated by AI and should be checked against your notes.
- The small offline model is slower and less accurate than the larger one.
- Photos work best when the text is upright and clearly visible.
